# Nanak Fabricators Limited — website

Next.js 15 (App Router) · TypeScript · Tailwind CSS 4 · Framer Motion · Geist fonts

    npm install
    npm run dev      # http://localhost:3000
    npm run build && npm start

## Before launch
- Replace the placeholder phone, WhatsApp number, email and hours in `lib/site.ts`.
- Swap the SVG vehicle drawings in `components/Vehicles.tsx` for real workshop photos when available.
- Confirm the sector list, chassis-partner wording and the three hero stats with the client.
